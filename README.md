# Banking System in C++

A simple console-based Banking Management System developed in C++.

This project allows users to create and manage bank accounts through a menu-driven interface. Account information is stored using file handling so that data can be retained between program executions.

## Features

- Create a new bank account
- Balance enquiry
- Deposit money
- Withdraw money
- Close/Delete an account
- Display all accounts
- Exit the application
- Store account data using file handling
- Minimum balance validation

## Technologies Used

- C++
- Object-Oriented Programming (OOP)
- STL `map`
- File Handling
- Exception Handling
